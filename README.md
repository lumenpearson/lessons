# Lessons — школьный дневник

Расписание уроков, замены, домашнее задание и события класса —
для школ России. Приложение на Android, админка — в Telegram, и виджет любого
размера, который показывает, что происходит прямо сейчас.

Учитывает то, чем российская школа отличается от абстрактной: шестидневка,
недели по числителю и знаменателю, замены, сокращённые дни, и одиннадцать
часовых поясов от Калининграда до Камчатки.

> Дизайн и архитектура вдохновлены [sameerasw/essentials](https://github.com/sameerasw/essentials).
> Что именно взято и что сделано иначе — в [docs/architecture.md](docs/architecture.md).

## Фишка — виджет

Виджет тянется на любой размер и меняет содержимое вместе с ним:

| Размер | Что показывает |
| --- | --- |
| 2×1 | состояние и обратный отсчёт одной строкой |
| 2×2 | + текущий/следующий предмет и прогресс |
| 4×2 | + два следующих урока |
| 4×4 | оставшееся расписание дня целиком |
| 5×5 | расписание + домашнее задание |

Состояний семь: **до уроков**, **урок**, **перемена**, **столовая/событие**,
**после уроков**, **выходной**, **нет данных**. Когда уроки заканчиваются,
виджет сам переключается на домашнее задание — на завтра, а в пятницу
на понедельник, и через каникулы тоже.

Две вещи, которые делают его пригодным к жизни:

* **Работает офлайн.** Room — единственный источник правды, сеть только
  наполняет его. Отсчёт продолжает идти без интернета.
* **Не будит телефон зря.** Вместо тика раз в минуту виджет ставит один точный
  будильник на ближайший звонок (`ScheduleEngine.nextTransition`), и учащает
  обновления только когда до конца урока осталось меньше десяти минут.
* **Знает время школы, а не телефона.** «Сейчас» считается в часовом поясе
  класса, поэтому родитель в Москве видит звонки новосибирской школы.

## Для российских школ

| Особенность | Как поддержана |
| --- | --- |
| Шестидневка | расписание задаётся на понедельник–субботу |
| Числитель / знаменатель | у урока в шаблоне есть чётность недели |
| Замены и отмены | отдельные записи на дату, шаблон недели не трогается |
| Сокращённые дни | своё расписание звонков на конкретную дату |
| Каникулы | день помечается как выходной, домашка едет на следующий учебный день |
| 11 часовых поясов | пояс хранится у класса, а не у сервера |

Пояс выбирается при создании класса и меняется в «⚙️ Класс → 🕒 Часовой пояс».
Время звонков при смене пояса не сдвигается — меняется только то, по какому
времени считается «сейчас».

## Быстрый старт

### Сервер

```bash
cd server
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
cp .env.example .env          # впишите BOT_TOKEN и OWNER_IDS
.venv/bin/python -m scripts.seed_demo        # демо-класс, код DEMO24
.venv/bin/python -m uvicorn app.main:app --reload
```

Проверить:

```bash
curl -s localhost:8000/api/v1/health
TOKEN=$(curl -s -X POST localhost:8000/api/v1/join \
  -H 'Content-Type: application/json' -d '{"code":"DEMO24"}' | jq -r .token)
curl -s "localhost:8000/api/v1/bundle?days=7" -H "Authorization: Bearer $TOKEN" | jq
```

Или через Docker:

```bash
BOT_TOKEN=... OWNER_IDS=... docker compose up --build
```

### Бот

1. Токен у [@BotFather](https://t.me/BotFather), свой id у [@userinfobot](https://t.me/userinfobot).
2. `BOT_TOKEN` и `OWNER_IDS` в `server/.env`.
3. `/start` в боте → он предложит создать первый класс и выдаст код для приложения.

Роли: **наблюдатель → редактор → администратор → владелец**. Добавить человека
редактором можно по номеру телефона: админ отправляет номер, человек нажимает
«Поделиться номером» в боте, и роль выдаётся автоматически. Подробно —
[docs/bot.md](docs/bot.md).

### Приложение

Готовый APK можно не собирать руками: **Actions → APK → Run workflow**, и
через несколько минут он лежит в артефактах прогона. Тег `v*` дополнительно
создаёт GitHub Release с приложенным APK.

Локально:

```bash
cd android
./gradlew assembleDebug     # или assembleRelease
```

Без настроенного keystore release-сборка подписывается debug-ключом: ставится
на телефон, но публиковать её нельзя. Как подключить свой ключ — в
[docs/build.md](docs/build.md).

При первом запуске приложение просит код класса — тот, что выдал бот.

## Честный статус

Прочитайте это до того, как планировать релиз.

**Что проверено.** И сервер, и приложение собираются и проходят тесты в CI на
чистом клоне.

| Проверка | Результат |
| --- | --- |
| `pytest` (сервер) | 86 тестов, зелёные |
| `ruff` (сервер) | чисто |
| `./gradlew test` | 71 тест, зелёные, включая 29 тестов движка состояний |
| `./gradlew assembleDebug` | APK собирается |
| `./gradlew assembleRelease` | APK собирается, R8 и сжатие ресурсов проходят |

Релизная сборка проверяется не только в CI, но и в том же прогоне, что и
отладочная: R8 и сжатие ресурсов — классический источник «в debug работало, в
APK сломалось», и ловить это на pull request дешевле, чем на релизе.

Сервер дополнительно проверен вживую: поднимался под uvicorn, отвечал на
`join` и `bundle`, отдавал замены, события, домашку и `next_school_day`.
Движок состояний прошёл проход по всем 1440 минутам учебного дня и все
одиннадцать российских часовых поясов.

**Что не проверено — и это важнее.** Приложение **ни разу не запускалось**: ни
на устройстве, ни на эмуляторе. Компиляция доказывает, что типы сходятся, и
ровно ничего не говорит о том, что происходит на экране. Не проверено ничего
из этого:

* виджет вообще ни разу не отрисовывался — ни в одном из пяти размеров;
* точность будильников `TickCadence` в реальном Doze;
* вёрстка экранов, тёмная тема, динамические цвета;
* поведение при первом запуске, вводе кода класса и потере сети;
* падения в рантайме, которых компилятор не видит.

Material 3 Expressive и Glance 1.3.0-alpha02 — альфы. Они скомпилировались,
но их поведение в рантайме на разных версиях Android никто не смотрел.

Версии зависимостей не выдуманы: AGP, Kotlin, KSP, Compose, Glance и
WorkManager взяты из `essentials`, а Room, Navigation, DataStore, Retrofit,
OkHttp и kotlinx-serialization — из `android/nowinandroid` со сверкой по Maven
Central. Первый прогон CI упал именно на выдуманных версиях, которых не
существует ни в одном репозитории.

**Чего нет вовсе.**

* Тестов UI и виджета. Логика состояний покрыта, отрисовка — нет.
* Уведомлений (напоминание о домашке, оповещение о замене). Каркас есть
  (`POST /api/v1/join` выдаёт токен устройства), push — нет.
* Вложений к домашнему заданию. Поле `attachment_url` в схеме есть, загрузки нет.
* Нескольких классов на одно устройство. Модель это позволяет, UI — нет.
* Справочника школ России. Название школы и город — просто текстовые поля;
  никакой привязки к реестру нет и не планировалась.
* Миграций. Схема создаётся через `create_all`; первое несовместимое изменение
  потребует Alembic.
* Rate limiting на `/api/v1/join`. Код из шести символов перебирается, если этим
  заняться всерьёз.

**Что стоит сделать первым.** Скачать APK из артефактов CI или собрать
самому, поставить на телефон, добавить виджет и прожить с ним один учебный
день. Компиляция пройдена, дальше вопросы только про рантайм и вёрстку — а их
не видно ниоткуда, кроме реального экрана.
